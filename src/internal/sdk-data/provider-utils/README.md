# Generated provider utility exports

This folder contains generated type exports for individual provider utility entry points.
Use [`../provider-utils.ts`](../provider-utils.ts) for the main provider utility types and
[`../../../protocols/provider-utils/`](../../../protocols/provider-utils/) for public adapters.

Refresh these files with the [SDK data generator](../../../../scripts/generate-sdk-data-types.mjs).
The generator owns the TypeScript files, and this README records their scope.
