## `LiquidDecisionModelId`

The source declaration does not provide a JSDoc description.

```text
type LiquidDecisionModelId = LiquidModelIds['decision'] | (string & {});
```

## `LiquidDecisionModelOptions`

Liquid decision models do not support provider-specific options.

```text
type LiquidDecisionModelOptions = Record<string, never>;
```

## `LiquidProvider`

Provider returned by the adapter, with Effect-based model selection for Liquid.

```text
export type LiquidProvider = ReturnType<typeof wrapProvider>;
```

## `LiquidProviderSettings`

Keep the native Liquid options and allow `apiKey` to resolve through Effect when the SDK
requests the value.

```text
export type LiquidProviderSettings<E = never, R = never> = EffectProviderSettings<SdkSettings, ResolverKey, E, R>;
```
