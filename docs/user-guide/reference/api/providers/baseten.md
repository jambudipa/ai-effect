## `BasetenPerformanceClient`

Implement this client to supply Baseten performance embeddings through Effects owned by
the provider scope.

```text
export interface BasetenPerformanceClient<E = never, R = never> {
    /**
     * Run when the SDK asks for performance embeddings. Keep the native request and response
     * shapes.
     */
    embed(...args: Parameters<NativePerformanceClient['embed']>): Effect.Effect<Awaited<ReturnType<NativePerformanceClient['embed']>>, E, R>;
}
```

## `BasetenPerformanceClientConstructor`

Keep SDK constructor arguments identical when supplying an Effect-based performance
client.

```text
export type BasetenPerformanceClientConstructor<E = never, R = never> = new (...args: ConstructorParameters<NativePerformanceClientConstructor>) => BasetenPerformanceClient<E, R>;
```
