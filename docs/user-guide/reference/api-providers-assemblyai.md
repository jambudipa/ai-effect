# assemblyai provider API

> **TL;DR:** This entry exposes 8 public exports through `@jambudipa/ai-effect/assemblyai`.

## Import

`@jambudipa/ai-effect/assemblyai` selects the package export for this provider. See the [provider source](../../../src/providers/assemblyai.ts).

SDK requests the value.

