# Tutorials

Follow a lesson to produce a visible result in a local project. Start with
the first requests if you are new to the package. The track indexes show any
required earlier lessons.

- [First requests](getting-started/README.md). Get a text result and collect a stream.
- [Generation lessons](generation/README.md). Work with structured output, tools, and model results.
- [Streaming lessons](streaming/README.md). Work with live chunks and see when a stream closes.
- [Provider lessons](providers/README.md). Inspect an adapter request and response.
- [Testing lessons](testing/README.md). Check model behavior with local fixtures.
- [Integration lessons](integrations/README.md). Practise with an integration that runs locally.
