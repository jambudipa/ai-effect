# Streaming lessons

Practise reading, stopping, and serving text streams with a model fixture. Use the project
from [Get your first text result](../getting-started/first-text-result.md).

1. [Print text as it arrives](print-text-as-it-arrives.md). Watch two fragments
   arrive before the answer completes.
2. [Stop a stream after its first fragment](stop-after-first-fragment.md).
   Check the request signal after an early stop.
3. [Inspect a streamed chat response](inspect-a-chat-response.md). Read the
   UI message events in an in-memory HTTP response.
