# First requests

Start here if you are new to ai-effect. Create a Node.js project, get a fixed
text result, and then collect a stream in the same project. Both lessons run
with a local model fixture.

1. [Get your first text result](first-text-result.md). Print the text and the number of model calls.
2. [Read your first text stream](first-text-stream.md). Collect text deltas and print the result.
