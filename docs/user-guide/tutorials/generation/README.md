# Build with generation and tools

Use these lessons after your first text request. Each lesson uses a local fixture and prints a result you can check.

- [Triage a support ticket with a schema](triage-a-support-ticket.md). Read an order ID and a priority from validated output.
- [Look up an order with a local tool](look-up-an-order.md). Read application data during a model request.
- [Rank two notes with embeddings](rank-short-notes.md). Score documents against a query with fixture vectors.
