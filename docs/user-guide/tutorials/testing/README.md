# Test AI requests locally

Follow these lessons to check a model request, trigger a failure, and change an
HTTP response. Each example runs locally with fixed data.

1. [Check a model request](check-a-model-request.md). Assert the answer, forwarded prompt, and call count.
2. [Recover from a model failure](recover-from-a-model-failure.md). Trigger a failure and return a fallback.
3. [Reset an HTTP fixture](reset-an-http-fixture.md). Restore the initial route response and clear the request history.
