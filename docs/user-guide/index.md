# ai-effect user guide

Use the Vercel AI SDK through Effect v4. The package provides lazy model
operations, scoped streams, and typed failures for TypeScript applications.

## Start here

[Get your first text result](tutorials/first-text-result.md) runs `AiSdk` with a
model fixture. The example uses no provider credentials. See the
[tutorials](tutorials/index.md) for the next lesson.

## Get a task done

The [how-to guides](how-to/index.md) cover model selection, typed output, tools,
streaming, tests, MCP, and React chat.

## Look up the API

The [reference](reference/index.md) covers package setup, import paths, and the
core, provider, protocol, framework, and integration APIs.

## Understand the design

The [explanations](explanation/index.md) describe how the wrapper handles SDK
calls, scope closure, and package resolution.

## Work on the package

The [contributor guide](contributing/index.md) describes the repository checks.
