# Search and media

Use these guides to prepare and rank search results, save generated files, or transcribe recordings.

- [Embed a batch of documents](embed-a-batch.md). Match each returned vector to its document ID.
- [Rerank a shortlist of search results](rerank-search-results.md). Reorder existing search hits and keep their original IDs.
- [Save a generated image to a file](save-a-generated-image.md). Write generated bytes with a filename that matches their MIME type.
- [Save generated speech to an MP3 file](save-generated-speech.md). Turn a line of text into an audio file.
- [Save a generated video clip](save-a-generated-video.md). Write clip bytes in a format the player can open.
- [Transcribe a recording with timestamps](transcribe-an-audio-file.md). Read text and time ranges for a local audio recording.
