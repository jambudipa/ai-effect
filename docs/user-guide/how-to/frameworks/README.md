# Framework guides

Use these guides to connect a UI to an existing model endpoint and control the
request from the component.

- [Add a stop button to a React chat](stop-a-react-chat-answer.md). Cancel the
  request from the current chat.
- [Display a streamed completion in Solid](show-a-solid-completion.md). Show
  text from a Fetch endpoint as it arrives.
- [Render a React chat](render-a-react-chat.md). Run chat commands at the event boundary.
