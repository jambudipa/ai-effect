# Use an MCP client

Use these guides when your application needs to work with a Model Context
Protocol server. Keep the client and the operations that use it in one scope.

- [Connect to a local MCP process](connect-to-a-local-process.md). Open a standard I/O transport for a Node server.
- [Read a resource from an MCP server](read-a-resource.md). Resolve a URI and read the text parts.
- [Attach a local schema to an MCP tool](add-a-schema-to-a-tool.md). Validate inputs and execute a named tool.
- [Connect an MCP client](connect-an-mcp-client.md). Open a scoped connection to an MCP server.
