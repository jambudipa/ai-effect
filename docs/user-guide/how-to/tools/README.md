# Tools

Use these guides to call application functions during generation and handle the result in your own workflow.

- [Let a model continue after a tool call](continue-after-a-tool-call.md). Give the model a bounded number of steps after it reads application data.
- [Ask for approval before a tool writes data](approve-a-tool-action.md). Pause for confirmation and resume with the recorded decision.
- [Handle a failed tool call](handle-a-tool-failure.md). Distinguish missing data, tool failures, and request failures.
- [Define an Effect tool](define-a-tool.md). Supply an input schema and an Effect callback.
