# Streaming guides

Use these guides to send model output to an HTTP client or observe events in
the application that consumes them.

- [Serve streamed text from a Fetch handler](serve-a-plain-text-response.md).
  Return a text body to a client that reads fragments.
- [Serve UI message events from a chat endpoint](serve-a-ui-message-response.md).
  Return events that include message parts for the chat transport.
- [Observe tool failures during a streamed answer](observe-tool-errors-in-a-stream.md).
  Log the failed tool call while the stream continues.
- [Consume a text stream](consume-a-text-stream.md). Read text deltas and inspect the result metadata.
