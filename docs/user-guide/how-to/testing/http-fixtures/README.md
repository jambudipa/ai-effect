# Test with HTTP fixtures

Use a fetch fixture when you need to control the HTTP responses an application
receives. Check the request history while the fixture is active.

- [Check a JSON request body](check-a-post-body.md). Assert the fields from a recorded POST.
- [Simulate an upstream outage](simulate-an-upstream-outage.md). Return an error before a successful response.
- [Reuse an HTTP fixture in Vitest](reuse-a-fixture-in-vitest.md). Reset the fixture between tests in the same suite.
