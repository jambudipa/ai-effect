# ai-effect user guide

Use the Vercel AI SDK through Effect v4. The package provides lazy model
operations, scoped streams, and typed failures for TypeScript applications.

## Start here

[Get your first text result](tutorials/getting-started/first-text-result.md) runs
`AiSdk` with a local model fixture. See the [tutorial tracks](tutorials/README.md)
for more hands-on lessons.

## Get a task done

The [how-to guides](how-to/README.md) group working examples by task, including
model selection, structured output, tools, media, streaming, and integrations.

## Look up the API

The [reference](reference/README.md) covers package setup, import paths, and the
core, provider, protocol, framework, and integration APIs.

## Understand the design

The [explanations](explanation/README.md) describe how the wrapper handles SDK
calls, scope closure, and package resolution.

## Work on the package

The [contributor guide](contributing/README.md) describes the repository checks.
